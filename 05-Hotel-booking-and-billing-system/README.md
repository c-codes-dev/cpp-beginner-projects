🏨 Hotel Booking & Billing System

A beginner-friendly C++ Hotel Booking and Billing System created to practice using functions, parameters, return values, conditional operators, and switch statements.

📌 About the Project

This program simulates a simple hotel booking system. It allows a customer to enter their information, choose a room, select the number of nights, and calculate the total hotel bill.

The program also provides a 10% discount for customers aged 65 or above.

✨ Features

- 👤 Customer name and age input
- 🏨 Three different room types
- 💰 Different prices for each room
- 🌙 Number of nights selection
- 🧮 Automatic room cost calculation
- 🎁 10% senior-citizen discount
- 🧾 Final bill calculation
- 🔧 Uses multiple C++ functions
- 🔀 Uses "switch" statements
- ❓ Uses the conditional (ternary) operator

🏨 Room Prices

Room Type| Price per Night
Single Room| 5000
Double Room| 8000
Deluxe Room| 12000

🔧 Functions Used

"calculateRoomCost()"

Calculates the total room cost:

price * nights

"customerInfo()"

Displays the customer's name and age.

"roomType()"

Displays the selected room using a "switch" statement.

"getRoomPrice()"

Returns the room price according to the customer's selected room.

"calculateDiscount()"

Calculates a 10% discount if the customer is 65 or older.
