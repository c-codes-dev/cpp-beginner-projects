# C++ Arrays Practice

This folder contains my beginner C++ practice programs for learning **1D arrays**.

## What I Learned

These programs helped me practice:

* Creating and initializing arrays
* Taking input into arrays
* Accessing array elements using indexes
* Traversing arrays using `for` loops
* Calculating the sum of array elements
* Finding the largest and smallest values
* Counting elements based on conditions
* Searching for values in an array
* Counting how many times a value appears

## Programs

### 1. Student Marks Analyzer

Takes marks as input, stores them in an array, and displays the marks.

### 2. Array Statistics

Calculates the **sum, largest value, and smallest value** in an array.

### 3. Even Number Counter

Checks the elements of an array and counts how many numbers are even.

### 4. Array Search Counter

Takes a number from the user, searches the array, and counts how many times that number appears.
