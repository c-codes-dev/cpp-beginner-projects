🎬 Movie Ticket Counter

A beginner-friendly C++ program that calculates a movie ticket price based on the customer's age and student status.

 What This Program Does........

- Takes the customer's age as input.
- Asks whether the customer is a student ("Y/N").
- Determines the ticket category and base price.
- Gives students a $2 discount.
- Displays the final ticket price.
- Shows a message based on the final ticket price.

🧠 C++ Concepts Used

- "if-else-if" ladder
- Conditional operator ("?:")
- "switch" statement
- Variables
- "cin" and "cout"
- Basic input and output

💰 Ticket Prices

Category| Base Price
Child (12 or under)| $5
Adult (13–64)| $12
Senior (65+)| $8
Student Discount| $2 off
