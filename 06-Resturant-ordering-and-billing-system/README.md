🍔 Restaurant Ordering & Billing System

This is a beginner-level C++ project that simulates a simple restaurant ordering and billing system.

📌 About the Project

The program allows a customer to:

- Enter their name
- View the restaurant menu
- Select an item
- Enter the quantity
- Order multiple items using a "while" loop
- Calculate the total bill
- Get a 10% discount if the bill is 5000 or more
- Display the final bill

🍽️ Menu

Item| Price
Burger| 500
Pizza| 800
Pasta| 600
Sandwich| 400

🧠 C++ Concepts Used

- Functions
- Parameters and arguments
- Return values
- "switch" statement
- "while" loop
- "if" condition
- Ternary operator
- Variables and data types
- Basic calculations
- User input and output

🔄 How the Program Works

1. The customer enters their name.
2. The menu is displayed.
3. The customer selects an item and enters its quantity.
4. The program calculates the cost of the order.
5. The "while" loop allows the customer to order another item.
6. The loop continues until the customer chooses "n".
7. The total bill is calculated.
8. A 10% discount is applied if the total bill is 5000 or more.
9. The final bill is displayed.

I created this project to practice C++ functions and loops and to understand how different programming concepts can work together in a real-life example.
